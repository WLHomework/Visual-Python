# Visual Python 项目总结

Visual Python 是面向 **Python 与 Manim** 的桌面图形化编程工作台：用积木搭程序，实时生成 Python，可在本机运行、渲染动画、配音，并内置 AI 智能体。工程文件扩展名为 `.vpy`。

---

## 一、技术栈

### 1. 桌面与运行时

| 层 | 技术 | 用途 |
|---|---|---|
| 桌面壳 | **Tauri 2** | 无边框窗口、托盘、单实例、资源协议、打包 NSIS/MSI |
| 后端 | **Rust**（crate `visual-python`） | 进程、文件、网络、密钥、TTS、AI 流式、插件 zip |
| 前端 | **React 19 + TypeScript + Vite 8** | 全部 UI |
| 测试 | **Vitest** | 前端单测 |

Rust 侧主要依赖：`tokio`、`reqwest`（HTTPS）、`tokio-tungstenite`（WSS）、`keyring`（Windows 凭据）、`zip`、以及内嵌的 **Codex App Server**（`vendor/codex-rs`）。

Tauri 插件：`dialog`、`fs`、`clipboard-manager`、`notification`、`opener`、`shell`、`single-instance`、`log`。

### 2. 编辑与图形化

| 技术 | 用途 |
|---|---|
| **Blockly 13**（Zelos 渲染器） | 积木画布、工具箱、序列化 |
| **blockly/python** | 积木 → Python |
| **Monaco Editor**（`@monaco-editor/react`） | 纯代码 / 分栏只读代码 |
| **Pyright** | Python 语言服务（补全、签名、跳转、诊断） |
| **@wasm-fmt/ruff_fmt** | Python 格式化 |
| **MathLive** | 公式积木可视化编辑 |
| **Lucide** | 图标 |

### 3. AI 与文档渲染

| 技术 | 用途 |
|---|---|
| OpenAI 兼容 **Chat Completions / Responses** | 对话与工具调用 |
| **Codex App Server**（Rust） | Responses 协议智能体 |
| **react-markdown + remark-gfm + remark-math + rehype-katex** | AI 回复 Markdown / 公式 |
| **highlight.js** | 回复中的代码高亮 |
| **KaTeX** | 数学公式 |

### 4. 语音与媒体

| 技术 | 用途 |
|---|---|
| 阿里云百炼 **Qwen-Audio 3.0 TTS** | 配音合成（HTTP / `wss://` 双工） |
| Web Audio / MediaRecorder | 音色复刻录音、样本修剪、试听 |
| HTML `<video>` / `<img>` | Manim 渲染预览 |

### 5. 工程与数据

| 形式 | 用途 |
|---|---|
| `.vpy`（JSON） | 工程：积木、代码文档、插件状态、资源、模式 |
| `localStorage` | 主题、布局、模型配置、插件开关、对话等 |
| 系统凭据库 | AI / TTS API Key |
| 工程资源目录 | 导入的音频等 |

## 二、工作区模式

三种模式共用同一套积木工作区与代码模型，切换时保持工程：

| 模式 | 界面 | 代码来源 |
|---|---|---|
| 纯图形化 `visual` | 仅积木 | 积木生成（只读代码面板隐藏） |
| 图形化+代码 `split` | 左积木右代码 | 积木实时生成，Monaco 只读 |
| 纯代码 `code` | 仅 Monaco | 可编辑的多文档 `.py`，积木仍保存在工程中 |

模式状态：`src/workspaceMode.ts`。积木生成：`src/pythonBlocks.ts`。代码文档：`src/sceneDocuments.ts`。

## 三、功能与所用技术

### 1. 图形化编程

**做什么：** Scratch 风格搭 Python；分类工具箱、搜索、大纲、撤销重做、缩放网格、积木输入单行/自动换行。

**技术：** Blockly、自定义 Python 积木（`pythonBlocks.ts`、`pythonSyntaxBlocks.ts`）、插件注册的积木与工具箱、MathLive（公式）。

---

### 2. 代码编辑

**做什么：** 多文档标签、语法高亮、补全、签名提示、跳转、查找替换、格式化、大纲、缩进与字体设置、AI 改码高亮（保留/撤销）。

**技术：** Monaco、Pyright（`src/pyrightClient.ts` + `scripts/prepare-language-server.mjs`）、Ruff WASM、自研补全/诊断（`pythonCompletions.ts`、`pythonSyntaxDiagnostics.ts`、`pythonRuntimeDiagnostics.ts`）。

---

### 3. 运行 Python

**做什么：** 用本机 CPython 跑当前工程；超时 60 秒；标准输入；输出/报错定位到积木或行号。

**技术：** Tauri `invoke("start_python")`，Rust 拉起解释器，stdout/stderr 事件回前端；积木模式用 Blockly 行号映射定位积木。

---

### 4. Manim 渲染

**做什么：** 渲染视频或静帧；选场景、分辨率、透明背景、截取动画步骤；进度条；预览、系统播放器打开、资源管理器定位。

**技术：** Rust `render_manim` 调本机 Manim；前端解析进度（`renderProgress.ts`）；积木侧场景名提取、静帧预处理、配音/本地音频时间轴预处理。

---

### 5. 配音与 TTS

**做什么：** 旁白积木、与动画同步的配音；语速/情感等；角色音色；试听；缓存。

**模型限制（硬约束）：**

- `qwen-audio-3.0-tts-flash`：系统音色，无 instruction  
- `qwen-audio-3.0-tts-plus`：系统音色 + 复刻 + instruction  

**技术：** 前端 `ttsConfig.ts` / `voiceoverRoles.ts`；Rust HTTP 或 DashScope WebSocket（`wss://dashscope.aliyuncs.com/api-ws/v1/inference`）；合成音频写入缓存目录，Manim 渲染前注入。

---

### 6. 音色复刻

**做什么：** 选文件或麦克风录音（12–20 秒）、波形修剪、质量检查、提交百炼、导入为角色、云端列表删除。

**技术：** Web Audio + ScriptProcessor 录音；Rust `create_cloned_voice` multipart；Plus 模型音色 ID。

---

### 7. 工程资源（音频）

**做什么：** 导入/去重/替换/删除 wav/mp3 等；拖到画布生成「播放本地音频」积木；缺失检测。

**技术：** Tauri 对话框 + `plugin-fs`；工程 JSON 记录资源；Blockly 拖放 MIME `application/x-visual-python-resource`。

---

### 8. 工程文件

**做什么：** 新建/打开/保存/另存为 `.vpy`；未保存提示；最近工程；导出 `.py`；关联打开 `.vpy`。

**技术：** JSON 工程（`projectFile.ts`）；Tauri dialog/fs；Windows 文件关联；草稿 `localStorage`。

---

### 9. 示例库

**做什么：** 菜单加载 Python 基础与 Manim 示例（按难度分组）。

**技术：** `src/examples/` 内 Blockly 序列化；加载时生成 Python 写入代码文档。纯代码模式打开示例会留在纯代码；再切分栏会按积木重新生成，避免 Monaco 复用旧 `generated.py` 模型。

---

### 10. 插件系统

**做什么：** 内置 + 外部 zip 插件；积木、工具箱、设置、命令、工程数据、Agent 工具、Python 依赖声明。

**内置插件：** Manim、NumPy、Pandas、Matplotlib（始终启用）。

**技术：** `pluginRegistry`（`src/plugins/`）；外部插件 `plugin.json` + `index.js`（动态 `import`）；Rust 发现/安装/删除插件目录；首次启用信任确认；`pip` 检测与安装（可选国内镜像）。

文档：`docs/plugin-development/README.md`、`docs/manim-plugin/README.md`。

---

### 11. AI 编程助手

**做什么：** 侧栏对话；智能体 / 计划模式；思考强度；读工程、改代码、跑程序、渲染、装依赖（需确认）；流式回复与思考；建议按钮；多会话本地存储。

**协议：** OpenAI 兼容 Chat Completions 与 Responses；自动探测，失败则回退。默认开启思考。

**技术：**

- 前端 Agent：`agentCore.ts`、`aiProtocol.ts`、`AiAssistantPanel.tsx`  
- Responses：Rust Codex App Server 客户端  
- 工具：`agentV2/toolRegistry.ts` + 宿主 `visualPythonHost.ts` / Blockly / 插件工具  
- 流式：`liveStream.ts`（按帧吐字，完成后再 Markdown）  
- 展示：react-markdown、KaTeX、highlight.js  
- 密钥：设置页 + Rust keyring  
- 代码模式可流式预览 `replace_code` / `edit_code` 到 Monaco  

---

### 12. Python 环境

**做什么：** 检测本机解释器、手动选 `python.exe`、状态栏切换；版本范围校验。

**技术：** Rust `validate_python` / 环境枚举；前端状态栏菜单。

---

### 13. 输出 / 问题 / 预览

**做什么：** 三页底部面板：运行日志、诊断列表（点击定位）、渲染预览。运行成功自动切到输出。

**技术：** React 面板 + Tauri 事件流；视频 `convertFileSrc`；通知插件（后台渲染完成）。

---

### 14. 外观与窗口

**做什么：** 多主题、无边框拖拽、最小化/最大化/关闭、关闭时询问/托盘/退出、启动闪屏。

**技术：** CSS 变量主题（`visualPythonThemes`）；Tauri 窗口 API、托盘菜单；`splash.html`。

---

### 15. 设置中心

**做什么：** 外观、编辑器字体字号缩进、保存时格式化、Python 环境、AI 模型（地址/模型/协议/思考）、关闭行为；Manim 渲染与配音单独设置页。

**技术：** React 对话框 + `localStorage` + Tauri 密钥存储。

---

## 四、目录速查

```
app/
  src/                  前端（App、积木、AI、插件、示例）
  src-tauri/            Rust 后端与 Tauri 配置
  vendor/codex-rs/      Codex App Server
  docs/                 Manim 说明、插件开发、本文
  scripts/              语言服务器、文档生成
```

核心入口：`src/main.tsx` → `src/App.tsx`；后端入口：`src-tauri/src/lib.rs`。
