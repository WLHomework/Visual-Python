from machine import Pin
import time

LED_PIN = 2  # 接实际板载 LED 所在 GPIO
led = Pin(LED_PIN, Pin.OUT)

while True:
    led.value(1)
    time.sleep(0.5)
    led.value(0)
    time.sleep(0.5)
  • 按“外接 LED 接 GPIO2”的常见接法编写，亮灭各 0.5 秒；改 LED_PIN 即可换脚。
  • 若使用开发板自带的 WS2812 RGB 灯（常见 GPIO38 或 GPIO48），需要 neopixel 驱动，不能直接当作普通 Pin 使用。
  • 当前未连接开发板，因此未执行设备端运行验证。
