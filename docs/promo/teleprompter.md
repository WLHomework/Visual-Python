## 00:25–01:05 为什么做

[画面：代码 → 日志 → 积木]

我教过也写过不少 Python 入门。初学者卡住的地方，往往不是语法。

第一，代码跑起来之前，环境先劝退一批人。

第二，代码和结果之间隔着一层，学生不知道自己改的那一行到底发生了什么。

第三，从积木到文本，中间有一道断层；很多图形化工具，积木是积木，代码是代码，两边各说各话。

Manim 更典型：效果很好，但命令行、场景类、动画对象，对新手不友好。

硬件也是，MicroPython 能跑，但接线、烧录、串口，每一步都能劝退。

所以我想要一个东西：用积木的方式写程序，但右边永远有真实的 Python；既能做数学动画，也能控制开发板。

## 01:05–02:35 Manim

[操作：示例 → Manim → Hello Manim；切分屏]

先看 Manim。

左边是积木，右边是实时生成的 Python。这个场景叫 Hello Manim，其实只有三块：创建文字、播放书写动画、等待一秒。

右边就是真正的 Manim 代码：`Text`、`Write`、`self.wait`。不是伪代码，也不是截图。

[操作：点“动画场景”积木]

我点一下这块积木，右边对应的代码会高亮。学生看到的是“我改的是哪一块，代码是哪一行”。

[操作：字号 56 → 96]

我把字号从 56 改成 96。你看，右边的 `font_size` 立刻变了。

[操作：点渲染]

然后点渲染。平台会自动提取场景名、起 Manim 进程、把日志接回来。第一次渲染会慢一点，这里我加速一下。

[画面：渲染完成，播放]

渲染完，预览直接播。整个过程不需要碰命令行。

## 02:35–03:50 代码与 AI

[操作：切代码模式，再切回分屏；打开 AI 助手]

很多图形化工具到此为止：积木是积木，代码是代码。

Visual Python 把两边绑在一起：积木改，代码变；代码也能通过 AI 回到积木。

[操作：输入提示词]

我让 AI 做一件事：生成一个标题从左侧飞入的 Manim 场景。

注意，它不是给我一段代码让我自己贴。它调用工具，先生成完整程序，再由平台的确定性转换器把程序变成真实积木，校验通过后一次性提交到工作区。

这套机制叫“代码优先、积木落地”。AI 写的是代码，但最后落到工作区的是积木；转换不了的语句会报错、给行号，不会悄悄糊过去。

对我来说，AI 的价值不是替我写，而是把“想法 → 可运行的作品”这段路缩短，同时保留可检查的中间结果。

## 04:25–06:05 ESP32-S3

[操作：新建工程 → ESP32-S3]

现在换硬件。

新建工程，四种工作台：Python、ESP32-WROOM、ESP8266、ESP32-S3。我选 S3。

工具箱完全变了：GPIO、PWM、I2C、SPI、串口、Wi-Fi、蓝牙、MQTT，还有传感器、执行器、灯光。

[操作：示例 → 灯光 → 板载 RGB 循环]

先做一个不用接线的：板载 WS2812。

重复执行里放四块颜色：红、绿、蓝、黄，每块等 0.5 秒。

右边生成的是 MicroPython，不是 Arduino C。

[操作：插 USB、选串口、连接、运行]

插上 USB，选串口，连接，运行。

[画面：板子灯变色]

你看板子上的灯，它真的在跑。

[操作：切设备文件]

这时候再看设备文件：`boot.py`、`main.py` 都在板上；也可以直接读文件、传文件、删文件。对教学来说，硬件不再是黑盒。

如果手边没有板子，可以切模拟器，逻辑先跑通，再上真机。

---

## 06:05–06:50 光照 + OLED（可选）

[画面：俯拍接线；操作：打开光照工程、运行]

再往前走一步，接 I2C：BH1750 光照传感器和一块 OLED。

S3 默认 SDA 是 8，SCL 是 9，3V3 和 GND 共地。接线之前一定先拔 USB。

积木里初始化 I2C、读光照、OLED 显示、刷新。

[画面：手遮传感器，OLED 数值变化]

运行之后，手一遮，数值掉下来；拿开，数值升上去。

这里有一个细节：平台会在编辑期校验引脚能力，比如你把一个只能输入的引脚拿去做 PWM，它会直接告诉你不行。很多硬件课的坑，在拖积木的时候就挡住了。

从 Manim 到传感器，学生练的是同一件事：把一个问题拆成对象、顺序、参数和反馈。

## 06:50–07:30 架构与教学

[画面：架构图，快切 Manim/串口/固件]

底层是四层：界面、前端核心、桌面服务、本地运行时。

Python、Manim、Pyright、串口、固件烧录都在本地，断网也能用。

对我来说，它不是一个“图形化皮肤”，而是一个可解释的编程环境：积木是结构，代码是文本，运行结果是反馈，AI 是加速器。

这套东西现在有 601 个积木，Manim、NumPy、Pandas、Matplotlib，三类 ESP 开发板，127 个测试文件。

当然它不完美：AI 生成还在迭代，硬件覆盖也有限。但我先把一条完整的路跑通了。
