# Visual Python 宣传片录制脚本

> 目标：B 站主片 8 分钟，另剪一版 60 秒抖音竖屏。
> 形式：真人出镜 + 屏幕录制 + 硬件特写；也可以不露脸，只保留画外音。
> 语气：第一人称、像在给同事演示，不要念参数，不要喊口号。
> 核心一句话：**同一套积木范式，既能做 Manim，也能落到 ESP32 上。**

---

## 一、录制前准备

### 1. 三个必须提前跑通的 Demo

| Demo | 用什么 | 录制前检查 |
| --- | --- | --- |
| Manim 主演示 | `Hello Manim` 示例 | 积木能显示、代码能生成、渲染能出片、预览能播放 |
| AI 生成演示 | AI 助手 + 一个简单场景 | 提前跑通过一次，保留“生成前/生成后”两个工程，防止现场模型超时 |
| 硬件主演示 | ESP32-S3 + 板载 WS2812 | 串口能连、程序能烧、板载 RGB 能变色 |
| 硬件进阶（可选） | ESP32-S3 + BH1750 + SSD1306 OLED | I2C 能扫到 0x23 和 0x3C，手遮传感器数值会变 |

> 建议：Manim 主演示用 `Hello Manim`，因为它只有三块积木，观众一眼能看懂“积木和代码一一对应”。  
> 想要更“数学”的画面，可以额外提前渲染一段线性函数/勾股定理，作为 B-roll 插入，不要在主线里现场搭。

### 2. 硬件准备

**主演示：ESP32-S3 板载 WS2812**

- 板子：ESP32-S3（板载 WS2812 一般在 GPIO48，1 颗灯）。
- 线：**USB 数据线**，不是只能充电的线。
- 串口：插上后在设备管理器确认 COM 口；录制时选对端口。
- 固件：提前烧好 MicroPython；不要在现场第一次烧固件。
- 节目效果：灯珠颜色红→绿→蓝→黄，每 0.5 秒一次。

**进阶演示：BH1750 + OLED（I2C）**

| 模块引脚 | 接到 ESP32-S3 |
| --- | --- |
| BH1750 VCC | 3V3 |
| BH1750 GND | GND |
| BH1750 SDA | GPIO8 |
| BH1750 SCL | GPIO9 |
| BH1750 ADDR | GND（地址 0x23） |
| OLED VCC | 3V3 |
| OLED GND | GND |
| OLED SDA | GPIO8 |
| OLED SCL | GPIO9 |

- OLED 常见地址 `0x3C`。
- **接线前先拔 USB**；只接 3.3V，不要接 5V；两块模块共地。
- 如果模块没有上拉电阻，SDA/SCL 各加 4.7k 上拉到 3.3V。
- 不同 S3 开发板的 I2C 引脚可能不同，以板卡丝印为准；平台默认是 SDA 8 / SCL 9。

**备用板：ESP32-WROOM / ESP8266**

| 板卡 | 板载 LED | 默认 I2C |
| --- | --- | --- |
| ESP32-S3 | WS2812，GPIO48 | SDA 8 / SCL 9 |
| ESP32-WROOM | GPIO2 | SDA 21 / SCL 22 |
| ESP8266-ESP12E | GPIO2，低电平点亮 | SDA 4 / SCL 5 |

### 3. 屏幕与录音

- 录屏：1920×1080，60fps，CQP 18–20；只录 App 窗口，不录整个桌面。
- App 窗口：1600×1000 或 1920×1080；代码字号 14–16；关闭无关面板。
- 桌面：隐藏图标、任务栏自动隐藏、关闭微信/QQ/浏览器通知。
- 麦克风：单独录，不要用耳机麦；离嘴 15–20cm，稍偏轴，避免喷麦。
- 音量：目标 -16 LUFS，峰值不超过 -1.5 dB；录 10 秒环境底噪，后期降噪。
- 灯光：正面柔光，别让 OLED 反光；拍硬件时稍微俯拍。

### 4. 录制顺序

先录屏幕主演示，再录硬件特写，最后录真人出镜/口播。  
每一段单独录，**不要一镜到底**；每段开头拍一下手或说“第 X 段开始”，方便对轴。

### 01:05–02:35｜Manim：积木、代码、渲染

6. 点“渲染”，展示渲染日志/进度。

**操作**
- 第 3 步：点积木后停 1 秒，让高亮出现。
- 第 5 步：改字号后停 2 秒，不要马上点渲染。
- 渲染等待时间如果超过 10 秒，后期加速，但保留“正在渲染”的界面。

**口播**
> 先看 Manim。
>
> 左边是积木，右边是实时生成的 Python。这个场景叫 Hello Manim，其实只有三块：创建文字、播放书写动画、等待一秒。
>
> 右边就是真正的 Manim 代码：`Text`、`Write`、`self.wait`。不是伪代码，也不是截图。
>
> 我点一下这块积木，右边对应的代码会高亮。学生看到的是“我改的是哪一块，代码是哪一行”。
>
> 我把字号从 56 改成 96。你看，右边的 `font_size` 立刻变了。
>
> 然后点渲染。平台会自动提取场景名、起 Manim 进程、把日志接回来。第一次渲染会慢一点，这里我加速一下。
>
> 渲染完，预览直接播。整个过程不需要碰命令行。

**字幕/花字**
- `Hello Manim`
- `积木 = 结构`
- `代码 = 文本`
- `渲染 = 反馈`

**备注**

### 02:35–03:50｜代码与 AI：不是聊天，是改工作区

**画面**
1. 切到“代码模式”，展示完整 Python。
2. 切回分屏。
3. 打开右侧「AI 编程助手」。

6. 结果：工作区出现新积木，右侧代码同步。
7. 点运行/渲染，播放结果。

**操作**
- AI 生成过程如果超过 20 秒，后期 2–4 倍速，保留“正在调用工具”的关键帧。
- 生成后先停 2 秒，再点渲染。

**口播**
> 很多图形化工具到此为止：积木是积木，代码是代码。
>
> Visual Python 把两边绑在一起：积木改，代码变；代码也能通过 AI 回到积木。
>
> 我让 AI 做一件事：生成一个标题从左侧飞入的 Manim 场景。
>
> 注意，它不是给我一段代码让我自己贴。它调用工具，先生成完整程序，再由平台的确定性转换器把程序变成真实积木，校验通过后一次性提交到工作区。
>
> 这套机制叫“代码优先、积木落地”。AI 写的是代码，但最后落到工作区的是积木；转换不了的语句会报错、给行号，不会悄悄糊过去。
>
> 对我来说，AI 的价值不是替我写，而是把“想法 → 可运行的作品”这段路缩短，同时保留可检查的中间结果。

**字幕/花字**
- `代码优先`
- `积木落地`
- `可检查的 AI`

**备注**
- 这一段是全片的技术核心，语速放慢。

### 06:05–06:50｜硬件进阶：光照传感器 + OLED

## 四、镜头与剪辑规范

### 1. 屏幕录制

- 只录 App 窗口，不录桌面；分辨率 1920×1080，60fps。
- 鼠标移动要慢；点击前停 0.3 秒，点击后停 1 秒。
- 不要频繁切窗口；需要切代码/积木时，用同一窗口内的模式按钮。
- 代码字号 14–16；积木缩放到能看清字段；AI 面板不用时关掉。
- 录制前清空输出/问题面板，避免旧报错入镜。

### 2. 真人出镜（可选）

- 半身，眼平，50mm 左右；背景干净，不要背光。
- 说话看镜头，不要看屏幕；演示时再看屏幕。
- 穿纯色衣服，避免细条纹（摩尔纹）。
- 小窗放在右下角，不要挡字幕和代码。

### 3. 硬件特写

- 俯拍 45°，柔光从侧面打，避免 OLED 反光。
- 先对焦灯珠/屏幕，再开机；不要手持晃动。
- 拍一组空镜：USB 插入、板子灯亮、手遮传感器、OLED 数值变化。
- 线材用短线，颜色区分：红 3V3、黑 GND、黄 SDA、白 SCL。

### 4. 剪辑

- 开头 3 秒内必须出现成品或硬件动作。
- 段落之间硬切；只有章节之间用 0.2s 淡入淡出。
- 关键代码/数值加 1.3–1.6 倍数字变焦，配 1px 高亮框。
- 字幕：1080p 下 28–32px，最多两行；关键词用青色 `#2DD4BF`。
- BGM：低频氛围，音量压到 -28 dB 左右，人声出现时自动 duck。
- 音效：点击、渲染完成、灯变色可以加轻量 whoosh/pop，不要盖过人声。

### 5. 录音

- 单独录，48kHz/24bit；离嘴 15–20cm，稍偏轴。
- 每段先录 3 秒静音，后期采样降噪。
- 口误不要停整段，停半句，重读那一句；剪辑点放在句间。
- 语速：B 站 240–260 字/分钟；抖音 300 字/分钟左右。
- 句尾往下压，不要每句都上扬；技术词说清楚，不要吞字。

## 五、失败预案（现场不要慌）

| 问题 | 处理 |
| --- | --- |
| Manim 渲染失败 | 切提前渲染好的 MP4，口播“这段我提前渲染，逻辑一样”；不要演成功 |
| 渲染太慢 | 录制时保留“正在渲染”，后期 4–8 倍速；不要剪掉所有等待 |
| AI 超时/报错 | 切提前录好的生成前后对比；口播“模型有波动，这里用我提前跑的结果” |
| 串口连不上 | 换数据线/换 USB 口/关其他串口工具；仍不行切模拟器 |
| 板载灯不亮 | 确认板卡型号和 LED 引脚；S3 板载 WS2812 一般 GPIO48；不要现场改接线 |
| OLED 不亮 | 查 3V3/GND、SDA/SCL、地址 0x3C；先用手电照屏看是否上电 |
| 传感器数值不动 | 用手遮/手电测试；确认 ADDR 接地（0x23） |
| 麦克风有底噪 | 录 10 秒环境音，后期降噪；不要用耳机麦 |
| 桌面弹出通知 | 开录前开“专注模式”，关闭微信/QQ/浏览器通知 |
