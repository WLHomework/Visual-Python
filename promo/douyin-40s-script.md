# 我用图形化编程实现了 Manim！— 抖音 40 秒版 v1

## 成片参数

- 画幅：1080×1920，9:16
- 时长：约 40 秒
- 帧率：30fps
- 字幕：全程硬字幕，底部安全区内
- 配音：TTS 快速迭代，先用 3 个音色试听

## 逐秒脚本

| 时间 | 画面 | 旁白 |
|---|---|---|
| 0–3s | 代码视图快速滚动，停在 `class ... construct` | Manim 是数学动画的天花板，但我不会 Python。 |
| 3–7s | 切到积木工作区，Hello Manim 示例出现 | 所以，我把它做成了积木。 |
| 7–16s | 放大积木区：场景、文字、Write、等待；右侧代码同步 | 拖一个场景，拖一个文字，再拖一个动画。右边，就是真正的 Manim 代码。 |
| 16–24s | 点击渲染，进度条加速，预览播放 “Hello Manim!” | 点一下渲染，动画真的跑起来了。 |
| 24–32s | 改字号/颜色，积木与代码同步高亮 | 每一块都能改，每一行代码都能看懂。 |
| 32–37s | 三栏快切：积木 / 代码 / 渲染 | 不会 Python，也能让数学动起来。 |
| 37–40s | 落版：Visual Python | 这是 Visual Python。 |

## 画面原则

- 只录 App 窗口，不录桌面。
- 鼠标移动慢，点击后停 0.5 秒。
- 代码字号临时设为 12，保证竖屏可读。
- 渲染进度条后期加速，不剪掉等待过程。
- 结尾 3 秒留白，给标题和关注引导。
