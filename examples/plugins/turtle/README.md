# Turtle 海龟绘图

面向 Python 初学者的 Visual Python 外部插件。插件提供 40 个中文积木，生成仅依赖 Python 标准库 `turtle` 的完整程序，无需安装第三方包。

## 安装插件

1. 打开 Visual Python 设置。
2. 进入“插件”，点击右上角的“安装插件”。
3. 选择 `visual-python-turtle-plugin-1.0.2.zip`。
4. 在插件列表中启用“Turtle 海龟绘图”，并确认信任该插件。
5. 返回图形化编辑区，工具箱中会出现“海龟绘图”分类。

Turtle 需要图形桌面环境。请使用包含 Tk 支持的本机 Python 运行，远程无桌面环境通常不能显示绘图窗口。

## 积木分组

| 分组 | 积木能力 |
| --- | --- |
| 程序 | 创建完整程序入口、画布、默认海龟和事件循环 |
| 移动 | 前进、后退、左右转向、移动到坐标、回到原点、设置朝向 |
| 画笔 | 抬笔、落笔、线宽、速度、形状、显示、隐藏、清空、复位、撤销 |
| 颜色与填充 | 设置画笔色、填充色、开始填充和结束填充 |
| 绘制 | 圆、圆点、正多边形、文字和盖章 |
| 画布 | 标题、背景颜色和窗口大小 |
| 交互 | 按键、画布点击和海龟点击事件 |
| 状态 | 当前横坐标、纵坐标、方向和画笔状态 |

每个项目应从“海龟绘图程序”积木开始，其他命令连接在入口内部。数字、文字和颜色槽均可连接 Visual Python 的标准值积木。

## 使用 AI 助手

启用插件后，AI 可以通过 `inspect_turtle_capabilities` 读取 Turtle 的积木组合规则，并优先使用 Visual Python 的 `compose_workspace` 一次提交积木方案；需要精确连接契约时再批量获取模板，局部修复才使用其它工作区工具。

可直接提出目标，例如：

- “创建一个彩色五角星，不要运行。”
- “画 5 个半径逐渐增大的同心圆。”
- “让方向键控制海龟移动，上下左右分别移动 20 步。”

为了减少歧义，建议说明颜色、尺寸、是否填充、是否需要交互，以及是否立即运行。运行程序属于外部操作，AI 会沿用 Visual Python 的统一确认流程。

## 独立运行生成的 Python

“海龟绘图程序”入口会生成完整 Python 文件，基本结构如下：

```python
import turtle

def main():
    screen = turtle.Screen()
    pen = turtle.Turtle()
    # 积木生成的绘图命令
    screen.mainloop()

if __name__ == "__main__":
    main()
```

将代码保存为 `.py` 文件后，可脱离 Visual Python 独立运行：

```powershell
python turtle_demo.py
```

## 教学示例

### 示例一：彩色五角星

1. 放入“海龟绘图程序”。
2. 设置画笔颜色和填充颜色。
3. 开始填充。
4. 重复 5 次：前进 120 步，向右转 144 度。
5. 结束填充并隐藏海龟。

这个示例适合讲解循环、转角和正多角星的几何关系。

### 示例二：同心圆

1. 放入“海龟绘图程序”，将绘制速度设为 0。
2. 抬起画笔，移动到第一个圆的底部，再落下画笔。
3. 绘制半径分别为 30、60、90、120 的圆。
4. 每次绘制前切换颜色，并移动到对应的圆底部。

这个示例适合讲解坐标、半径、变量和规律递增。

### 示例三：方向键控制海龟

1. 放入“海龟绘图程序”。
2. 添加四个“当按下按键时”积木。
3. 上、下方向键分别连接前进和后退 20 步。
4. 左、右方向键分别连接向左和向右转 15 度。

运行后先点击 Turtle 窗口，再使用方向键控制。这个示例适合讲解事件、回调和交互程序。

## 开发与打包

在 Visual Python 项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/package-turtle-plugin.ps1
```

脚本会验证 manifest 和源文件，并在 `artifacts` 目录生成 ZIP。安装包根目录仅包含 `plugin.json`、`index.js` 和 `README.md`。
